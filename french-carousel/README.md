# Карусель «Види френчу»

Instagram 4:5 (1080×1350), 8 слайдів: обкладинка, 6 видів френчу, фінал із закликом.
Зліва фото (одне або два одне над одним; сітка 2×2 теж підтримується), справа текст на темному фоні у стилі KM Nail Artist
(Cormorant Garamond + Montserrat, золото `#c9a45c`, лінія з ромбом). Готові слайди — `out/01.png` … `out/08.png`.

| Слайд | Вид | Фото (`source/`) |
|---|---|---|
| 01 | обкладинка | 11 |
| 02 | Кольорове покриття (гель-лак мокко / сірий + білий край) | 05, 08 |
| 03 | Френч на базі (молочна / нюдова камуфлююча база) | 07, 09 |
| 04 | Колір + колір | 02, 01 |
| 05 | Френч + принт | 04, 10 |
| 06 | Асиметрія | 06 |
| 07 | Арт-френч | 03 |
| 08 | «Який френч ваш?» | — |

Фон: рука, нігті й рукав не змінюються; решта кадру розмита, приглушена й затемнена.
01, 02, 03, 11 — без обробки (фон уже чистий).

Перезібрати:
```bash
pip install "rembg[cpu]" opencv-python-headless
python3 scripts/masks.py isnet-general-use 04 05 06 07 08 09 10   # маски → masks/
python3 scripts/process.py                                        # source/ → photos/
node render.js                                                    # slides.json → out/
```
Тексти, кадрування (`pos`, `zoom`) — у `slides.json`.
