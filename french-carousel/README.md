# Карусель «Види френчу»

Instagram 4:5 (1080×1350): зліва фото, справа текст на темному фоні у стилі KM Nail Artist
(Cormorant Garamond + Montserrat, золото `#c9a45c`, лінія з ромбом).

1. Фото покласти в `photos/`: `cover.jpg`, `01.jpg` … `07.jpg`, `end.jpg`.
2. Тексти — у `slides.json` (назва, тег, опис, пункти). Кількість слайдів = кількість записів у `slides`.
3. `node render.js` → `out/01.png` … (обкладинка, види, фінальний слайд із закликом).
