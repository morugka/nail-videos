# Карусель «Види френчу»

Instagram 4:5 (1080×1350), 7 слайдів: обкладинка, 5 видів френчу, фінал із закликом.
Зліва фото (одне, два одне над одним або чотири сіткою 2×2), справа текст на темному фоні у стилі KM Nail Artist
(Cormorant Garamond + Montserrat, золото `#c9a45c`, лінія з ромбом). Готові слайди — `out/01.png` … `out/07.png`.

| Слайд | Вид | Фото (`source/`) |
|---|---|---|
| 01 | обкладинка | 11 |
| 02 | База вирішує (мокко, сірий, молочна, нюд) | 05, 08, 07, 09 |
| 03 | Колір + колір | 02, 01 |
| 04 | Френч + принт | 04, 10 |
| 05 | Асиметрія | 06 |
| 06 | Арт-френч | 03 |
| 07 | «Який френч ваш?» | — |

Фон: рука, нігті й рукав не змінюються; решта кадру розмита, приглушена й затемнена.
01, 02, 03, 11 — без обробки (фон уже чистий).

Перезібрати:
```bash
pip install "rembg[cpu]" opencv-python-headless
python3 scripts/masks.py isnet-general-use 04 05 06 07 08 09 10   # маски → masks/
python3 scripts/process.py                                        # source/ → photos/
node render.js                                                    # slides.json → out/
```
Тексти, кадрування (`pos`, `zoom`) — у `slides.json`.
