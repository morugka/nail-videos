# Обкладинки KM Nail Artist

Шрифти акаунта:
- **Cormorant Garamond** (Regular/Medium) — великі заголовки й акцентні слова;
  золотий рядок під назвою теж ним, великими літерами (`cover45-info.js`, `"subStyle":"ref-cg"`)
- **Montserrat** (Light/Regular, без жирного) — дрібний текст, підписи, пояснення

Reels 9:16 (1080×1920) за брифом: логотип 200 px, 80 px зліва / 290 px зверху,
текст поза верхніми 290, нижніми 340 px і правою смугою 120 px.

```bash
# 1) фон: фото → 1080×1920 (зсув вниз, масштаб, x початку кадру в px оригіналу, flip)
python3 prep916.py photos/green-ring.jpg photos/green-ring-916-flip.png 330 0.86 280 flip
# 2) обкладинка: фон, файл, верх тексту, кінець і початок затемнення під логотипом
node cover916.js photos/green-ring-916-flip.png out/3-etapy-green-916.png 540 620 330
```

`render.js` — ранні варіанти обкладинки «3 етапи» (старий шрифт, без брифу).
