# 14 днів до 40 — серія сторіс

Щоденна серія у сторіс: два тижні до сорокаріччя, переоцінка життя.

- `SCRIPT.md` — сценарій: 15 днів (14 → 1 → 40), тексти сторіс, що знімати, інтерактиви
- `out/covers/` — обкладинки-картинки 1080×1920 для кожного дня
- `public/photos/` — фото робіт для обкладинок, `public/logo-km.png` — логотип
- `out/stories/` — ті самі обкладинки з анімацією, 5 с (MP4)
- `src/days.ts` — числа й теми днів (змінюєш тут, потім робиш новий рендер)
- `src/Cover.tsx` — дизайн обкладинки у стилі сторінки: чорний фон, білі капітелі, золота лінія з ромбом, мідне число; циферблат із 14 нігтиків заповнюється щодня

**Фото на фон.** Поклади фото в `public/photos/` і допиши дню в `src/days.ts`: `photo: "photos/day-14.jpg"`. Тоді замість циферблата буде фото, а число й заголовок стануть зверху.

## Як працювати

```bash
npm i
npx remotion studio                                         # попередній перегляд
npx remotion still Cover-14 out/covers/cover-14.png          # одна обкладинка
npx remotion render Story-14 out/stories/story-14.mp4 --crf=18 --pixel-format=yuv420p
```
