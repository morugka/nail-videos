# Обкладинки для постів

- `out/<назва>.png` — для каруселі/фото, 3:4 (1080×1440)
- `out/<назва>-reels.png` — для Reels, 9:16 (1080×1920); у сітці профілю видно середню частину 3:4, текст уже в ній

Стиль сторінки: чорний фон, шрифт Cormorant, перший рядок слонова кістка, другий золото, золота лінія з ромбом.

- `src/Root.tsx` — тексти обкладинок (додати нову = скопіювати блок)
- `public/photos/` — фото. Зараз там **вирізки зі скриншотів (низька якість, лише для превʼю)**: замініть оригінальними фото з тими самими іменами й перерендерте.

```bash
npm i
npx remotion studio                                  # попередній перегляд
npx remotion still zazhralys-porahuiemo out/zazhralys-porahuiemo.png
```
