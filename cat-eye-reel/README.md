# Reels «Котяче око» — етапи нанесення

`out/cat-eye-reel.mp4` — готовий ролик 1080×1920, 30 fps, 18 с (база → колір → магніт → ефект), без звуку (музику додати в Instagram).
`out/cat-eye-cover.png` — кадр для обкладинки.

- `clips/` — вихідні відео (не в git; завантажуються з чернетки релізу `clips-1`)
- `build.py` — монтаж: вибір шматків, трекінг пальця (ніготь в одній точці кадру), темна обробка фону, написи
- `overlays.js` — написи (Cormorant Garamond, білий + золото) → `overlays/*.png`

```bash
node overlays.js && python3 build.py
```
