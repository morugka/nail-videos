# CURSE OF THE DEEP — колаж

Горизонтальний колаж 1920×1080, 13 с, зібраний у [Remotion](https://remotion.dev).
Три колонки: зліва великий палець, по центру безіменний з кальмаром, справа по черзі
вказівний (зелений), середній (фіолетове плетіння) і мізинець (мідний дріт).
Напис: «Моє наймасштабніше творіння».

- `out/nail-collage.mp4` — готовий ролик
- `source/` — вихідні відео (з релізу `Deep`)
- `public/*.mp4` — вирізані фрагменти: фон затемнено, шкіру оживлено, колір нігтів не змінено
- `src/Composition.tsx` — монтаж: кадрування кожної панелі, золоті лінії, напис
- `scripts/clean.py` — затемнення фону (Python + OpenCV)

| Колонка | Файл | Звідки |
| --- | --- | --- |
| ліва, великий | `thumb.mp4`, `thumb-b.mp4` | `v58` 0–5.6 с, `v43` 17.8–24.4 с (уповільнено ×0.8) |
| центр, кальмар | `squid-a.mp4`, `squid-b.mp4` | `v48` 3–12.8 с, `v55` 10.3–14.3 с |
| права, інші три | `green.mp4`, `purple.mp4`, `copper.mp4` | `v58` 16.8–21.8 с, `v58` 37.3–42.3 с, `v49` 11.3–16.3 с |

## Як працювати

```bash
npm i
npx remotion studio                                          # попередній перегляд
npx remotion render NailCollage out/nail-collage.mp4 --crf=16   # рендер
```

Повторна обробка фрагмента (потрібні `pip install opencv-python-headless numpy`):

```bash
python3 scripts/clean.py source/v48.mp4 3 12.8 public/squid-a.mp4 0.85
```
